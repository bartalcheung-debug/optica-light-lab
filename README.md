# 光迹 Optica · 光学交互实验室

中文光学交互学习平台：调节参数，观察光线与计算结果的对应关系。

- 单透镜成像：凸透镜、凹透镜、实像与虚像。
- 双透镜系统：等效焦距、后焦距、无焦扩束与缩束。
- 折射与全反射：斯涅尔定律、临界角及全反射。

直接打开 `index.html` 即可使用；也可通过 GitHub Pages 从 `main` 分支根目录发布。页面内嵌脚本、样式和 SVG，无构建步骤，无运行时外部依赖。参考资料链接需要网络。

几何光学模型用于学习，采用理想薄透镜与近轴近似，未模拟像差、衍射、有限口径或偏振；不作为工程光学设计验证工具。

计算与解释参考 OpenStax《University Physics Volume 3》和 TU Delft《Interactive Optics》，具体参考链接位于每个模型的“原理与公式”面板。
