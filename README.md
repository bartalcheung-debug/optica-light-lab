# 像差实验室 · 点光源追迹

移动点光源，经双凸球面透镜逐面折射，在可移动像面上观察几何像差。三维最多显示 12 条代表光线；二维小窗独立显示 801 个单色或 1,203 个三色入瞳采样的有效交点。

- 拖动黄色光源，或用 x / y / z 滑块定位；视场角由光源位置推导。
- 拖动紫色像面手柄或像面滑块，观察离焦；“最小光斑”计算最小质心 RMS 半径的像面。
- 小窗可切换固定比例尺，跟随光斑质心，或以光轴为中心观察像的移动。
- 球差、彗差、色差是同一透镜的实验条件预设，未人为分离或规定像差形状。

透镜采用 N-BK7，曲率半径 +28 / −28 mm，中心厚度 6 mm，通光半径 10 mm。计算真实球面交点与两次矢量斯涅尔折射，用 Sellmeier 公式计算色散。口径遮挡或全反射导致的无效光线被排除。RMS 是交点相对质心的均方根半径；包围光斑直径是两倍最大质心距离。二维光斑是等面积入瞳采样的几何散点图，不代表波动光学点扩散函数或辐射强度；不含衍射、偏振、镀膜与菲涅耳权重。

参考：[SCHOTT N-BK7](https://www.schott.com/shop/advanced-optics/en/Optical-Glass/N-BK7/c/glass-N-BK7)，[矢量折射公式（PBRT）](https://www.pbr-book.org/3ed-2018/Reflection_Models/Specular_Reflection_and_Transmission)。

直接打开 `index.html` 即可离线运行，无外部运行时依赖。修改 `src/` 后执行 `node build.cjs` 生成单文件页面；GitHub Pages 发布 `main` 根目录。
